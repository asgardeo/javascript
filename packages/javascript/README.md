> [!IMPORTANT]
> ⚠️ Do not use this package directly in your applications.
> `@asgardeo/javascript` is a framework-agnostic SDK that provides the core authentication functionality the other SDKs
> build on. Use the SDK for your framework instead, such as `@asgardeo/browser`, `@asgardeo/react`, `@asgardeo/vue`,
> `@asgardeo/nextjs`, `@asgardeo/nuxt` or `@asgardeo/express`.

## Installation

```bash
npm install @asgardeo/javascript
```
